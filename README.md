#AI Resume Filter & HR Automation :

An AI-based resume screening application that helps HR teams automatically filter resumes based on a job description. The system compares multiple candidate resumes, selects the most relevant profile, extracts the candidate's name and email, and can send an interview invitation using SendGrid. 
app.py

##How it works :

Upload a Job Description (PDF, TXT, or MD).

Upload multiple candidate resumes (PDF).

The HR Agent analyzes every resume and selects the best match for the job description.

A second AI agent extracts the selected candidate's name and email into a structured table.

If enabled, the Email Manager Agent generates a professional interview email and sends it via SendGrid.
